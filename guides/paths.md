# Paths

AEL ecosystem tries to avoid mixing up with your system.

Therefore, most installation are contained within `${AEL_HOME}`.

## Home

AEL lives, for most parts, inside `${AEL_HOME}`.

The default path is `~/.ael`, as defined in `.aelcore`.
